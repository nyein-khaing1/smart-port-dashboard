# Smart Port Dashboard

A practice full-stack dashboard inspired by real-time port intelligence systems.  
This project helps practise React, JavaScript, HTML, CSS, Python FastAPI, APIs, SQL, Git, and CI/CD concepts.

## Features

- Real-time style vessel dashboard
- KPI cards for vessels, delays, incidents, and congestion
- Vessel tracking table
- Incident timeline
- Search vessels by name
- Filter vessels by delay status
- Status badges for vessel states
- React frontend connected to a Python FastAPI backend
